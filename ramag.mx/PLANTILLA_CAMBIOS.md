# 📋 Plantilla de cambios — sitio RAMAG.mx

> Copia el bloque que necesites, llénalo y envíalo. Mientras más claro,
> más rápido se aplica. Si tienes captura de pantalla, súmala.

## 🟦 PLANTILLA ESTÁNDAR (cambios normales)

```
═══════════════════════════════════════════
 SOLICITUD DE CAMBIO #__
═══════════════════════════════════════════

📄 PÁGINA
   ( ) Inicio          ( ) Servicios
   ( ) Productos       ( ) Proyectos
   ( ) Clientes        ( ) Nosotros
   ( ) Contacto        ( ) Todas las páginas

📍 ¿DÓNDE ESTÁ LA SECCIÓN?
   (Descríbelo con tus palabras. Ej: "el recuadro
    azul oscuro con la pregunta '¿Por qué elegir
    RAMAG?'")
   →

🔧 TIPO DE CAMBIO
   ( ) Modificar algo existente
   ( ) Agregar algo nuevo
   ( ) Quitar / eliminar
   ( ) Mover algo de lugar

✏️ DESCRIPCIÓN DEL CAMBIO
   (Cuéntalo con tus palabras, sin tecnicismos)
   →

📝 TEXTO EXACTO (si aplica)
   (Si va a cambiar o agregar texto, pégalo aquí
    tal cual debe quedar publicado)
   →

🎨 REFERENCIA / INSPIRACIÓN (opcional)
   (URL, captura, ejemplo, color, etc.)
   →

⏱️ URGENCIA
   ( ) Urgente — hoy / mañana
   ( ) Normal — esta semana
   ( ) Cuando se pueda
═══════════════════════════════════════════
```

## ⚡ PLANTILLA RÁPIDA (cambios chicos de 1–2 líneas)

```
[Página] · [Dónde] → [Qué cambiar]

Ejemplo:
Inicio · botón "Cotizar" del menú → cambiar texto a "Solicitar cotización"
Contacto · teléfono del footer → actualizar a +52 33 1234 5678
Servicios · imagen del hero → reemplazar por foto adjunta
```

## 📌 Tips para que el cambio salga en una sola pasada

1. **Una solicitud = un cambio.** Si quieren mover y cambiar texto, son dos solicitudes.
2. **Sé específico con la ubicación.** "El recuadro azul" puede ser muchos. Mejor: "el recuadro azul al inicio de la página de Productos donde dice 'Descarga el catálogo'".
3. **Si es color/tamaño**, pongan referencias: "azul como el del logo", "más grande, similar al título principal".
4. **Si es texto**, peguen el texto final tal cual debe quedar publicado.
5. **Si tienen captura**, márquenla con flecha o círculo para indicar el punto exacto.
